Learn JSON

JavaScript Object Notation (JSON) is a data representation format. Commonly used for APIs, Config files in programming.
It is lightweight and easy to read/write due to its small size.
Its a superset of JavaScript so it intergrates easily with JavaScript.
JSON also intergrates easily with most programming languages.

JSON Types

  • Strings
  • Numbers
  • Booleans
  • Null
  • Arrays
  • Objects

JSON.parse is used to convert JSON string to JavaScript Object.
Syntax: JSON.parse(text, [, reviver])
A reviver is a function that can transform the resulting object before its returned. Text is a valid JSON string.

JSON.stringify is used to convert JavaScript Object to JSON string.
Syntax: JSON.stringify(value, [replacer], [space])
A replacer is a function that can transform the object before its converted to JSON. Value is a valid JavaScript object.
Space is used to add indentation to the JSON string.
